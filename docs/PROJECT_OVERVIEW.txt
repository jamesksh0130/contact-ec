■ Research Question
──────────────────────────────────────────────────────────────────────────────
  "Does ESM-2 (sequence) + Contact Map (structure) outperform
   sequence-only methods like HIT-EC (SOTA, Micro F1=0.93)
   for Enzyme Commission (EC) number prediction?"

■ Key Differentiators vs Prior Work
──────────────────────────────────────────────────────────────────────────────
  vs HIT-EC (Nature Commun. 2026, SOTA):
    - HIT-EC uses NO structural information
    - We add Contact Map (ResNet-50) → ablation shows +9.4% gain
    - We use 4-level hierarchical multi-label BCE (L1~L4 simultaneously)

  vs CLEAN-Contact (Commun. Biology 2024):
    - CLEAN-Contact: ESM-2 3B + contrastive kNN inference, L4 only
    - Ours: ESM-2 650M + supervised multi-label BCE, L1~L4 all levels
    - 4.5x lighter (675M vs 3025M params)
    - More principled multi-label: trains directly on multi-hot labels

■ Dataset
──────────────────────────────────────────────────────────────────────────────
  Source      : UniProt Swiss-Prot (reviewed, EC-annotated)
  Total       : 270,338 proteins
  EC classes  : L1=7, L2=75, L3=273, L4=5307
  Contact Maps: AlphaFold DB PDB → 256×256 binary (8Å threshold), 3-channel
  Embeddings  : ESM-2 650M CLS token (1280-dim), pre-extracted as .npy

  Splits (two protocols):
    Random split      → train:val:test = 8:1:1 (seed=42)
    Cluster split     → sequence identity <50% separation (strict OOD)

■ Model Architecture — Fusion V2 (MAIN MODEL)
──────────────────────────────────────────────────────────────────────────────
  [Sequence path]
    ESM-2 650M (frozen) → CLS embedding (1280-dim)

  [Structure path]
    Contact Map (3×256×256) → ResNet-50 → (512-dim)

  [Fusion]
    ESM proj (1280→1024) + GCA (Gated Cross-Attention) + gate
    → fused feature (1024-dim)

  [Hierarchical heads]
    L1: FC(1024→7)    L2: FC(1024→75)
    L3: FC(1024→273)  L4: FC(1024→5307)

  [Loss]
    L = 0.1·BCE(L1) + 0.1·BCE(L2) + 0.2·BCE(L3) + 0.6·BCE(L4)
    Multi-label BCE with l4_all_idxs multi-hot vectors

  Total params: ~675M

■ Paper Core Claims (Contributions)
──────────────────────────────────────────────────────────────────────────────
  1. Contact Map adds significant value: +9.4% over sequence-only (B2→V2)
     → This is the central ablation, independent of threshold/fine-tuning
  2. First hierarchical multi-label (L1~L4) structure-aware EC predictor
     → CLEAN-Contact only predicts L4; HIT-EC uses no structure
  3. Competitive with SOTA at 4.5x fewer parameters
     → ESM-2 650M vs CLEAN-Contact's ESM-2 3B
  4. Rigorous cluster-based OOD evaluation
     → Cluster split (seq identity <50%) more realistic than random split

■ Fairness Note on Fine-tuning
──────────────────────────────────────────────────────────────────────────────
  V2 (frozen)  → fair comparison with HIT-EC (no pre-trained backbone)
  V2-FT        → fair comparison with CLEAN-Contact (both fine-tune ESM-2)
  Both results will be reported in main table with explicit labeling.
  The core contribution (structure adds +9.4%) is independent of fine-tuning.
