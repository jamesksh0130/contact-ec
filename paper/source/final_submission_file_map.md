# Final Submission File Map

Prepared on 2026-08-09 for Contact-EC.

## Primary Target

BMC Bioinformatics.

## Files to Upload in the Journal System

1. `main.pdf`
   - Full non-anonymized manuscript with author information, ORCID, GitHub URL,
     declarations, ethics/consent statements, funding statement, conflict of
     interest statement, AI/LLM disclosure, and author contribution statement.

2. `main_blind.pdf`
   - Anonymized manuscript version. Use only if the submission system requests a
     blinded review file. BMC Bioinformatics normally does not require double
     anonymization, but this file is prepared as a fallback.

3. `supplementary.pdf`
   - Supplementary tables, additional evaluations, leakage audits,
     Foldseek/TM-score split details, seed-repeat summaries, calibration/error
     analyses, and extended benchmark checks.

4. Figure/source files
   - If the submission system asks for editable or separate source files, upload
     `bmc_bioinformatics_submission_source.zip`.

5. Administrative files
   - `cover_letter.md`
   - `declarations_for_submission.md`
   - `submission_checklist.md`
   - `journal_cost_options.md`

## Prepared Zip Archives

- `bmc_bioinformatics_submission_pdfs.zip`
  - Contains `main.pdf`, `main_blind.pdf`, and `supplementary.pdf`.

- `bmc_bioinformatics_submission_source.zip`
  - Contains LaTeX source, bibliography, class file, and figure files.

- `bmc_bioinformatics_submission_admin.zip`
  - Contains cover letter, checklist, declarations, and journal-cost notes.
