# Bioinformatics Submission Checklist

- Main manuscript: `main_submission.pdf`
- Supplementary information: `supplementary.pdf`
- Source archive: `bioinformatics_submission_source.zip`
- Article type: Original Paper
- Suggested category: Sequence analysis or Structural bioinformatics
- Review mode: Bioinformatics uses single-anonymized peer review, so author names should be visible in the final submitted manuscript.
- Completed: author name, affiliation, corresponding email, ORCID, funding statement, acknowledgements, conflict of interest, and author contribution statement have been added.
- Completed: repository URL has been added as `https://github.com/jamesksh0130/contact-ec`.
- Required before upload: provide ORCID iD `0009-0002-0708-748X` for the submitting author in the submission system.
- Required before upload: archive code/data release in a stable repository such as GitHub plus Zenodo if the manuscript is presented as software/tooling.
- Current repository wording: manuscript lists the GitHub repository directly. Add a Zenodo DOI if an archived release is created before submission.
- Current caveat: `main_submission.pdf` is compressed for submission, while the longer `../main.pdf` remains as the full working draft.
